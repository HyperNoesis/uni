End-to-end: `pnpm smoke` (tests/smoke.mjs) drives the real API and realtime servers: session, join, proximity refusal, activity, reward, idempotency. `pnpm e2e:realtime` (tests/e2e/two-clients.mjs) is the Phase 4 exit test: two clients see each other, movement arrives as deltas, emotes propagate, and a reconnect resumes position. CI starts both servers and runs both. Browser E2E (Playwright) still needs a networked install.
