# Characters (rigged GLB)
Put your model at `hero.glb` here and open `/character-lab` to preview it with animations.
- Export as `.glb` (binary glTF), skinned/rigged, animations included. Meshopt is OK; do NOT use Draco.
- Phone budget: about 10-15k triangles, textures 1K (2K max for the face), one material per body part if possible.
- Record the source + licence of every model in CAMPUS_ASSET_REGISTRY.md (the art brief requires it).
